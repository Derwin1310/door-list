# Doorlist

Esqueleto de una plataforma de tickets con Next.js App Router, TypeScript y Tailwind CSS 4.

## Desarrollo

```sh
pnpm install
pnpm dev
```

Abre http://localhost:3000.

## Verificación

```sh
pnpm lint
pnpm build
```

La única página es `/`. El evento está hardcodeado en `app/page.tsx` y el botón «Regístrame» aún no tiene acción. No hay base de datos ni autenticación.
